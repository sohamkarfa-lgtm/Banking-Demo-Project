## 🚀 QUICK START (4 Steps, ~6 minutes)

```bash
# Step 1: Install
pip install databricks-cli databricks-labs-python-sdk

# Step 2: Authenticate  
databricks configure --token --profile BANKING_DEMO

# Step 3: Validate
databricks bundle validate

# Step 4: Deploy
databricks bundle deploy --target dev
```

## 🔑 WHAT YOU NEED TO GET STARTED

### Before Deploying
1. **Databricks Workspace URL**
   - Get from: Databricks account page
   - Format: `https://adb-xxxxx.cloud.databricks.com`

2. **Personal Access Token**
   - Get from: Workspace → Settings → User Settings → Access Tokens
   - Create new token with "All" permissions
   - Keep it secure! 🔒

### That's It!
With these two items + the CLI installed, you can deploy in 5 minutes.
